# 全量鼠标标定分析：2026-10-30

## 结果

已从本次新四象限线性输入数据建立后轴base_link下的连续静态速度模型。严格约束左右镜像；前、后分别拟合。旧五方向速度端点和经验转动中心不参与此次拟合。生产映射源代码已更新，未重启实车节点或进行新模型驾驶。

令 x 为向右、y 为向前的归一化输入，圆内半径不超过1，则：

- y>=0：v=0.5366222196*y m/s
- y<0：v=0.4036709426*y m/s
- ω=-0.8108854254*x rad/s

圆外输入按半径等比例缩放至单位圆。输入位置本身仍是 center+8*(x,-y)，不套旧端点。速度模型连续，跨越y=0连续但前后斜率不同；沿任意固定方向、饱和前随半径线性变化。八方向只是显示参考轴，不是控制分档。

对实际整数HID偏移(dx,dy)，先取(x,y)=(dx/8,-dy/8)，若取整后落到圆外则按半径归一化后预测。这是对量化后App输入饱和的模型近似，在留出验证中优于不归一化的线性模型。

连续逆映射：x=-ω/0.8108854254；y=v/0.5366222196（前进）或v/0.4036709426（后退）。超出单位圆的请求沿输入方向饱和，再转换成整数HID点，重新计算该实际点对应的模型(v,ω)。最大前速与最大转速不能同时实现；可达范围为前后两个不同纵轴的半椭圆。

源：bag/mouse_calibration_20261030_141218，4个完整bag。总后轴odom 24,276条、映射5,474条、鼠标事件3,416条；按各bag里程计时间跨度合计443.18秒。各段有静止、输入切换、松键、再次拖动和停车，不将连续拖动瞬态当成静态标定样本。

## 验证

4折leave-one-bag-out：每次用其余3个bag拟合，再预测整个留出的bag中的稳定区间。比较无径向归一化和有归一化两种简单连续模型，后者误差更低。

|模型|vx RMSE m/s|ω RMSE rad/s|
|---|---:|---:|
|无径向归一化|0.02434|0.01732|
|采用径向归一化|0.02263|0.01123|

采用模型95分位绝对误差：vx=0.03631m/s、ω=0.02420rad/s。各折参数范围（每HID步）：前向0.06664–0.06734，后向0.05009–0.05089，转向0.10086–0.10166。参数较稳定，但这仍是同一录制会话的分组验证，模型类型也通过这些折选择，不是独立日期/工况的最终验收。

前进增益比后退高约33%；不强制前后对称。左右转向单独测得的速度/输入比例中位数约0.10186与0.10081rad/s/步，相差约1%，统一为0.10136。

严格左右对称的模型仍有可见线速度残差：模型减实测的中位数左侧约-0.02324m/s、右侧约+0.02175m/s。残差与角速度相关，等效杆臂诊断约0.0434m；这只是统计诊断，既不能证明真实轴心偏了4.3cm，也不能擅自改TF。可能涉及外参、参考点、运动耦合或估计误差，需进一步验证。按用户要求此次保留对称模型，把差异作为误差公开。

## 代码与使用边界

- scripts/calibrate_mouse_dataset.py：读取所有bag、质量审计、区间筛选、拟合和分组验证，可复现。
- projects/Ble2WChair/src/whill_controller/whill_controller/velocity_mapping.py：连续正向/反向映射，返回取整后实际预测。
- controller_node.py：增加navigation_velocity_mapping事件，记录目标速度、实际HID点、量化后模型速度。
- 纯测速入口仍不显示旧或新预测，继续独立记录实测，防止把模型输出当作观测。
- Nav2/控制器原有禁止倒车策略未改；映射数学上支持后退，不等于自动导航已授权倒车。
- 安全预测上游仍主要使用目标速度；本次新增实际预测日志用于检查误差，未声称已闭合上游量化补偿。
- 8计数半径的既有HID协议仍量化：大致每步前速0.067m/s、后速0.050m/s、角速0.101rad/s。软件模型连续不等于实际执行无限分辨率；若要求更细速度控制，需要改进底层HID分辨率并重新测量，不能改成软件抖动/PWM后声称已解决。
- App档位、载重和地面notes未填写，模型适用范围暂限本次录制条件；未把本次实验称为全工况保证。
